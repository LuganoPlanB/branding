# Brand reference

Mode: Read. Inherit the established Civic Digital Commons world and the existing branding guide's specimen-led reading order. This is an extraction into a standalone reference, not a replacement identity.

First viewport: an asymmetric editorial title and large original Plan ₿ logo on navy, with three named core color fields and a narrow energy band. Let the identity demonstrate itself immediately. Visible navigation leads directly to colors, vectors and model files.

Signature interaction: switch between light and dark to see semantic colors and live component examples change together; exact source palettes remain explicitly labeled. Copy a swatch or download its token data.

Reading sequence: identity, palette and gradients, typography and geometry, original vector library, practical UI specimen, maker resources and source lineage. Use open sections rather than a repeated card wall. At mobile widths stack specimens, wrap navigation and keep controls at least 44px high. Render essential reference content without JavaScript.

Pinned system: Inter, warm canvas, navy, civic blue, gold, one coordinated electric gradient. No new brand logo, no invented endorsement, no new commercial claims. Keep model files and human reference in the same repository.
