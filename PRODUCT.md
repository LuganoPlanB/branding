# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Confirmed: static HTML, CSS and JavaScript; GitHub Pages; code-first implementation.

## Users

Designers, developers, writers and models creating Plan B materials. They need concise rules, exact values, reusable assets and traceable sources.

## Product Purpose

A standalone shared branding repository and human-readable webpage consolidating the existing Civic Digital Commons system.

## Brand Commitments

Preserve the existing visual identity from vite-theme and luganoplanb.github.io, with ghost-theme and the other workspace projects as implementation references. Preserve original SVG artwork and distinguish Lugano's Plan ₿ marks from the Foundation's identity and partner marks.

## Capabilities and Constraints

Downloadable SVGs, CSS and JSON tokens, human guidance, model brief, responsive accessible examples, optional dark mode. No framework dependency or external runtime service. Brand and third-party assets retain their existing rights.

## Evidence on Hand

Source repositories and revisions are recorded in provenance.json. The original website's branding guide and vite-theme/DESIGN.md establish the inherited design world.

## Product Principles

- Show the actual asset or value beside its guidance.
- Keep human and model guidance consistent.
- Distinguish source facts from new application recommendations.
- Explain civic purpose in direct language without invented claims.
