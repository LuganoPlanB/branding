# Asset provenance and usage

The files in `logos/` are unmodified copies of `LuganoPlanB/vite-theme/src/theme/assets/logos/`. Exact source commits, original paths, view boxes, and SHA-256 hashes are recorded in `provenance.json` at the repository root.

The upstream logo README identifies https://planb.lugano.ch/planb-forum/media-assets/ as the source of the Lugano's Plan ₿ family. These are existing Lugano's Plan ₿ marks, not a newly invented Plan B Foundation logo. Partner marks identify their respective organizations and must not imply endorsement.

Use the original SVG proportions. Select dark grounds for the white and color variants: the color originals have white lettering with orange marks. Use the black variants on light grounds. Inspect the artwork: filenames saying “black” can still contain orange. The wide white variant has a different view box from the wide color variant; do not assume identical bounds.

This repository records and distributes the existing files for brand reference. It does not grant new trademark or third-party asset rights. No new blanket license is asserted for these assets.

## Bitcoin Roots project assets

`projects/bitcoin-roots/` contains the unchanged orange SVG and Lottie JSON from Bitcoin Roots, plus black and white fill-only SVG derivatives. Use black on light backgrounds and white on dark backgrounds. All SVGs remain transparent; preview backgrounds are not embedded. Preserve the original geometry and view box. See the project `manifest.json` for pinned source revision, exact hashes and transformations. Existing project rights remain applicable.
